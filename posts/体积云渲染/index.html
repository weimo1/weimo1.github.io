体积云渲染（云海/云层）

适用范围：Ray Marching 体积云、噪声密度建模、Beer 定律光照、蓝噪声抖动

一、一句话结论

体积云 = 包围盒 Ray Marching + 多层噪声密度（Shape/Detail/Weather） + Beer 吸收 + Henyey-Greenstein 内散射 + 蓝噪声抖动消除分层。64 步即可获得不错效果，结合大气散射透射率 LUT 实现天空融合。

3.3 蓝噪声抖动消除分层

效果对比：

  • 无抖动：明显分层条纹
  • 种子函数（fract(sin(...))）：分层几乎消失，但边缘不饱满
  • hash12：分层消失、饱满，开销更大
  • 蓝噪声：一次纹理采样，分层减弱但不如 hash 彻底

3.4 光照计算

最终混合：radiance = radiance * transmittance + scattering（云后的大气被云遮挡 + 云自身散射）。

3.5 踩坑记录

  • 密度一大就全白炸亮，薄处灰不透，厚处像发光体 → 需要仔细调 sigmaS/sigmaE 平衡
  • 性能：64 步 + 多层噪声采样 + 大气透射率查询 = 昂贵
  • 噪点：需要 TAA 或双边滤波后处理
  • 与天空融合：需要使用相同的透射率 LUT 保证一致性

四、面试准备

高频问法（≥8个）

  1. 体积云渲染的基本流程？ → 包围盒 Ray Marching → 每一步采样密度（多层噪声）→ 计算 Beer 吸收 + HG 内散射 → 累加
  2. 噪声层级如何分工？ → Weather Map（覆盖度/类型）→ Shape Noise FBM（云团形状）→ Detail Worley（边缘侵蚀）→ Height Gradient（云底圆化/云顶消隐）
  3. 如何消除 Ray Marching 的分层现象？ → 蓝噪声抖动初始步进偏移 + hash12 每步独立随机偏移
  4. Beer 定律在体积云中如何应用？ → 透射率 = exp(-∫σ·density·ds)，每步累乘衰减
  5. Henyey-Greenstein 相位函数的参数 g 含义？ → g∈(-1,1)，负=后向散射，0=各向同性，正=前向散射；云通常用正值（0.3-0.8）
  6. 如何与大气散射结合？ → 云中每个采样点用 TransmittanceLUT 查询太阳光到达该点的大气衰减
  7. 早停（early termination）条件？ → transmittance < 阈值（如 0.01），再往后的贡献可忽略
  8. 为什么云的颜色不是纯白？ → 大气散射染上蓝色调 + 太阳光在云中多次散射产生灰度
  9. 性能优化手段有哪些？ → 低分辨率渲染 + TAA 重建、自适应步长、减少噪声 octave、降低 Detail Noise 采样频率

反问点（≥5个）

  • 双瓣 HG 相位函数（两个 g）的物理意义？
  • Weather Map 为什么只采样 xz 平面？
  • 为什么 localPos * 0.8 而不是 * 1.0？
  • 云的包围盒如何确定大小和位置？
  • 高度雾和体积云能否共用密度场？

一句话答案（≥5个）

  • 体积云 = Ray Marching + 噪声密度 + Beer 消光
  • FBM = 多层 octave 叠加噪声
  • 蓝噪声抖动 = 低成本消除分层
  • HG 相位 = 光在云中偏向哪个方向散射
  • 早停 = 透射率太低后面不用算了
