# 二叉树遍历

二叉树四种遍历方式：先序（根→左→右）、中序（左→根→右）、后序（左→右→根）、层次（逐层从上到下）。

## 完整实现代码

# 五、源码解析和实践感悟

## 1. 递归遍历的统一模板——访问时机决定遍历类型

三种深度优先遍历（先序/中序/后序）共享相同递归结构，唯一区别是 `visit()` 的调用位置。

```cpp
// 统一递归模板：visit() 位置决定遍历类型
template<typename T>
void dfs(Node<T>* root, Order order) {
    if (!root) return;
    
    if (order == PRE)  visit(root);  // 先序：根→左→右
    dfs(root->left, order);
    if (order == IN)   visit(root);  // 中序：左→根→右
    dfs(root->right, order);
    if (order == POST) visit(root);  // 后序：左→右→根
}
// BST 中序遍历 = 升序输出（严格递增序列）
```

## 2. 迭代遍历——用栈模拟递归

递归本质是系统栈，迭代版需手动维护栈。中序迭代最经典：一直向左到底并入栈，弹栈访问，转右子树重复。

```cpp
// 中序遍历迭代版
vector<int> inorder_iterative(Node* root) {
    vector<int> result;
    stack<Node*> stk;
    auto cur = root;
    
    while (cur || !stk.empty()) {
        while (cur) {           // 一直向左到底
            stk.push(cur);
            cur = cur->left;
        }
        cur = stk.top(); stk.pop();  // 弹栈访问
        result.push_back(cur->data);
        cur = cur->right;            // 转右子树
    }
    return result;
}

// 后序遍历迭代版（双栈法：先序改 根→右→左，反转得 左→右→根）
vector<int> postorder_iterative(Node* root) {
    vector<int> result;
    if (!root) return result;
    stack<Node*> stk;
    stk.push(root);
    while (!stk.empty()) {
        auto node = stk.top(); stk.pop();
        result.push_back(node->data);    // 先序变体
        if (node->left)  stk.push(node->left);
        if (node->right) stk.push(node->right);
    }
    reverse(result.begin(), result.end());  // 反转为后序
    return result;
}
```

## 3. 层次遍历——队列实现 BFS

层次遍历用队列而非栈：根入队 → 出队访问 → 左右孩子入队 → 循环。可扩展为逐层输出（记录每层节点数）。

```cpp
// 层次遍历——标准 BFS
vector<vector<int>> level_order(Node* root) {
    vector<vector<int>> result;
    if (!root) return result;
    
    queue<Node*> q;
    q.push(root);
    
    while (!q.empty()) {
        int level_size = q.size();  // 当前层节点数
        vector<int> level;
        
        for (int i = 0; i < level_size; ++i) {
            auto node = q.front(); q.pop();
            level.push_back(node->data);
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        result.push_back(level);  // 每层一个 vector
    }
    return result;
}
// 复杂度：O(N) 时间 + O(W) 空间（W = 树的最大宽度，最坏 N/2）
```

## 实践经验

1. **前序/中序 + 中序/后序可以唯一重建二叉树**：前序确定根位置，中序划分左右子树，递归完成。但前序+后序不能唯一确定（无法区分左右子树分界）。LeetCode 105/106 经典题。
2. **Morris 遍历——真 O(1) 空间**：利用叶子节点的空闲右指针指向后继（threaded binary tree），遍历完再恢复。不需要栈，但会临时修改树结构。面试提到就能加分。
3. **层次遍历的\"锯齿形\"变体**：奇数层正序、偶数层反序（或反之），只需在 push 到 result 前根据层号决定是否 reverse。LeetCode 103 原题。
4. **迭代后序遍历是真·难写**：后序需判断\"左右子树都已访问\"才能访问根。技巧：标记法（每个节点入栈两次）或 prev 指针追踪上次访问节点。面试中手写迭代后序权重最高。
5. **DFS 递归在极端深度下栈溢出**：树深 >10 万层时递归可能爆栈（默认栈 ~8MB）。迭代版用 `std::stack` 分配在堆上更安全。但实际工程中这种深度通常是设计问题。
6. **遍历是树操作的基础**：序列化/反序列化 = 遍历的延伸，表达式树求值 = 后序遍历，BST 验证 = 中序遍历检查递增。掌握四种遍历的递归+迭代 = 搞定 80% 的树相关算法题。

# 六、面试准备

## 面试问答

**Q1: 二叉树的四种遍历方式及实现？**
A: (1) **先序**（根→左→右）：DFS，用于复制树、前缀表达式。(2) **中序**（左→根→右）：BST 中序=升序输出，验证 BST。(3) **后序**（左→右→根）：用于删除树（先删子节点）、后缀表达式。(4) **层次**（逐层 BFS）：用队列，求树的宽度/深度。递归实现简单，迭代版需栈/队列。

**Q2: 如何用前序+中序重建二叉树？**
A: 前序第一个元素是根；(2) 在中序中找到根位置，左边是左子树中序，右边是右子树中序；(3) 前序中对应长度的子数组分别是左右子树前序；(4) 递归构建。时间复杂度 O(N)（用哈希表 O(1) 查中序位置），空间 O(h)。前序+后序不能唯一重建。

**Q3: 递归遍历和迭代遍历的优缺点？**
A: 递归：代码简洁直观，但深度过大时栈溢出（系统栈 ~8MB 限制）。迭代：需手动维护栈/队列，代码量大，但栈在堆上分配更安全。实际面试优先写递归（简洁），被问\"树很深怎么办\"时答迭代+Morris 遍历。

**Q4: 层次遍历如何实现\"逐层输出\"？**
A: 标准 BFS + 记录每层节点数。`while (!q.empty())` 内先用 `int size = q.size()` 获取当前层节点数，然后 `for(int i=0; i<size; ++i)` 处理当前层，同时将下一层节点入队。这样外层循环每次处理一层，内层循环处理该层所有节点。

**Q5: 后序遍历的迭代实现为什么难？两种方法？**
A: 因为必须确认\"左右子树都访问完\"才能访问根。(1) **双栈法**：用先序变体（根→右→左）入栈，再反转输出（得左→右→根）。(2) **单栈+prev 指针**：记录上次访问节点，判断当前节点右子树是否已访问过。双栈法好记但多一个栈，prev 法省空间但逻辑复杂。

**Q6: Morris 遍历的原理？**
A: 利用叶子节点的空闲右指针（原为 NULL），将其指向中序后继节点（threaded binary tree）。步骤：当前节点 cur，若左子树为空→访问 cur→cur=cur.right；否则找左子树最右节点，将其右指针指向 cur→cur=cur.left。访问后恢复树结构。时间 O(N)，空间 O(1)。

**Q7: 二叉树的最大深度和最小深度怎么求？**
A: 最大深度：`1 + max(maxDepth(left), maxDepth(right))`，DFS/BFS 均可。最小深度（根到最近叶子的距离）：BFS 遇到第一个叶子节点即刻返回深度，DFS 注意当一侧子树为空时不能算 0（空子树不算路径）。最小深度用 BFS 更高效。

**Q8: 如何判断两棵二叉树是否相同（结构+值）？**
A: 递归判断：(1) 两节点均为 NULL → true；(2) 一个 NULL 一个非 NULL → false；(3) 值不同 → false；(4) 递归判断左子树相同且右子树相同。镜像对称问题类似，改为判断 root1.left 与 root2.right 对称。

## 陷阱与反问

| 陷阱 | 错误认知 | 正确理解 |
|------|---------|---------|
| 遍历就是简单的递归 | 极端深度（>10 万层）递归栈溢出 | 迭代版+Morris 遍历是深度场景的安全方案 |
| 任何人都会写层次遍历 | 逐层输出需要记录 level_size | 不用 level_size 则所有节点混在一层 |
| 后序迭代简单 | 后序需要确认左右子树都访问完 | 双栈法（先序变体+反转）是最简单的后序迭代实现 |
| 前序+后序能唯一重建树 | 不同结构的树可以有相同的前序+后序 | 必须有中序参与才能唯一确定结构 |
| 栈和队列性能一样 | 队列（deque 实现）和栈（vector 实现）内存布局不同 | 大数据量下栈（连续内存）常比队列（分块 deque）略快 |
