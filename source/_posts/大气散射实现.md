# 大气散射实现

> 适用范围：Rayleigh/Mie 散射模型、预计算大气散射、天空渲染、LUT 生成

## 一、一句话结论

大气散射 = **Rayleigh 散射（小粒子，蓝光） + Mie 散射（大粒子，灰白） + 臭氧吸收**。核心算法：沿视线方向积分单次散射（Ray Marching 6 步），每步计算太阳光到采样点的透射率 × 散射系数 × 到眼睛的透射率。倍增散射用预计算 LUT 加速。

---

## 二、核心概念解析（≥200字）

### 2.1 两种散射

| | Rayleigh（瑞利散射） | Mie（米氏散射） |
|---|---|---|
| 粒子大小 | 远小于波长（N₂、O₂） | 与波长相当或更大（气溶胶、水滴） |
| 波长依赖性 | ∝ 1/λ⁴（蓝光散射强） | 几乎无关 |
| 视觉效果 | 蓝天、红色日落 | 灰白雾霾、云 |
| 相位函数 | `(3/(16π))·(1+cos²θ)` | HG 相位函数（各向异性 g） |

### 2.2 散射方程（单次散射）

对于视线上的每个点 p₁：
```
inScattering(p₁) = 太阳光照 × Transmittance(太阳→p₁) × Scattering(p₁) × Transmittance(p₁→眼睛) × ds
```

积分用 6 步 Ray Marching 近似。

## 三、源码解析与实践感悟（≥1000字）

### 3.1 核心积分函数

```glsl
vec3 GetSkyView(AtmosphereParameter param, vec3 eyePos, vec3 viewDir, vec3 lightDir) {
    const int N_SAMPLE = 6;
    vec3 color = vec3(0.0);

    // 1. 求视线与大气层/地面的交点
    float atmosphereDist = RayIntersectSphere(vec3(0), param.PlanetRadius + param.AtmosphereHeight, eyePos, viewDir);
    float groundDist = RayIntersectSphere(vec3(0), param.PlanetRadius, eyePos, viewDir);
    float maxDist = (groundDist > 0.0) ? min(atmosphereDist, groundDist) : atmosphereDist;

    float ds = maxDist / float(N_SAMPLE);
    vec3 sunLuminance = param.SunLightColor * param.SunLightIntensity;

    for (int i = 0; i < N_SAMPLE; i++) {
        float t = (float(i) + 0.5) * ds;
        vec3 p1 = eyePos + viewDir * t;  // 采样点

        // 2. 太阳光到 p1 的光学深度
        float sunPathDist = RayIntersectSphere(vec3(0), param.PlanetRadius + param.AtmosphereHeight, p1, -lightDir);
        vec3 p2 = p1 + (-lightDir) * sunPathDist;

        vec3 t1 = Transmittance(param, p1, p2);  // 太阳→p1 透射率
        vec3 s  = Scattering(param, p1, lightDir, viewDir);  // p1 点散射系数
        vec3 t2 = Transmittance(param, p1, eyePos);  // p1→眼睛 透射率

        vec3 inScattering = t1 * s * t2 * ds * sunLuminance;
        color += inScattering;
    }
    return color;
}
```

### 3.2 Rayleigh 系数

```glsl
vec3 RayleighCoefficient(AtmosphereParameter param, float h) {
    const vec3 sigma = vec3(5.802, 13.558, 33.1) * 1e-6;  // 海平面散射系数
    float H_R = param.RayleighScatteringScalarHeight;       // 标高 ~8km
    float rho_h = exp(-(h / H_R));                          // 密度随高度指数衰减
    return sigma * rho_h;
}
```

**注意 sigma 三个通道差异巨大**：蓝光(33.1) >> 红光(5.8)，解释了为什么天空是蓝色——蓝光散射效率是红光的 6 倍。

### 3.5 坑点记录（原笔记）

- **单位统一**：全部 km 或全部 m，混用导致数量级错误
- **earth_center = (0, 0, -6370)**：要设负数让 camera-earth_center 切线从地表看向天空
- **view_ray 方向**：从相机出发指向天空，不要搞反
- **p1, p2 关系**：p1 是视线上采样点，p2 是太阳光进入大气层的边缘点

### 3.6 预计算 LUT

生成 Transmittance LUT（2D 纹理，x=高度，y=天顶角余弦），采样查询替代实时积分，大幅加速。

### 3.7 地平线模糊的成因

采用切片法存储散射积分结果，远处切片覆盖大范围深度（500-600m），相邻像素采样到相同/相近切片，三线性插值进一步混合——导致地平线区域产生柔和渐变。**这是存储策略的自然副作用**，恰好符合真实世界远景因大气透视而柔和的视觉效果。

## 四、面试准备

### 高频问法（≥8个）

1. **Rayleigh 散射和 Mie 散射的区别？** → Rayleigh∝1/λ⁴（蓝光散射强，蓝天），Mie 几乎无波长依赖（白云/雾霾）；相位函数不同
2. **单次散射的积分公式是什么？** → 沿视线积分：Σ(太阳光照 × T₁(太阳→p) × S(p) × T₂(p→眼睛) × ds)
3. **为什么天空是蓝色，日落是红色？** → 蓝光散射效率高（短波长），直射阳光中蓝光被散射掉，剩余红光穿透更远
4. **臭氧吸收主要吸收哪个波段？** → 红光和绿光（sigma=(0.65, 1.88, 0.085)），蓝光几乎不被吸收
5. **预计算 LUT 是什么？存什么？** → 2D 纹理（高度×天顶角余弦），存储透射率，避免实时 Ray Marching
6. **为什么用 6 步 Ray Marching 就够了？** → 大气散射变化平滑，6 步加插值足够精度；太多步性能差
7. **Beer-Lambert 定律在大气散射中怎么用？** → 透射率 = exp(-光学深度)，光学深度沿路径积分散射+吸收系数
8. **密度随高度的指数衰减模型？** → `ρ(h) = exp(-h/H)`，H 是标高（Rayleigh ~8km，Mie ~1.2km）
9. **地平线模糊是怎么产生的？** → 切片法远处覆盖大范围深度，相邻像素采样到相同切片，插值导致渐变

### 反问点（≥5个）
- 多次散射（multi-scattering）如何近似？
- 为什么 earth_center 要设成负数？
- Mie 的各向异性参数 g 的取值范围和物理含义？
- 如何将大气散射与体积云渲染结合？
- RayIntersectSphere 的数学原理？

### 一句话答案（≥5个）
- Rayleigh = 蓝天（蓝光散射强 6 倍）
- Mie = 白云（波长无关，各向异性）
- 单次散射 = 沿视线加总太阳光穿透来的能量
- LUT = 查表代替实时积分
- 标高 = 密度衰减到 1/e 的高度
