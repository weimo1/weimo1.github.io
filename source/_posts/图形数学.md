## 一、核心概念

- 定义：图形数学是计算机图形学的数学基础，涵盖向量代数、矩阵变换、光线求交、反射折射等，用于描述和计算三维空间中的几何关系。
- 关键词：向量运算、点积/叉积、矩阵变换、光线-球体求交、反射向量、投影
- 适用场景/边界：渲染管线中的光照计算、射线检测（Ray Casting/Ray Tracing）、碰撞检测、物理模拟；不涉及微积分层面的辐射度计算。

## 二、详细解析（≥200字）

### 原理拆解（三层递进）

**第一层：向量运算基础**

图形学中最核心的向量运算：
- **点积（Dot Product）**：\( a \cdot b = |a||b|\cos\theta \)，用于计算投影长度、夹角、光照强度（Lambert 漫反射：\( I = N \cdot L \)）
- **叉积（Cross Product）**：\( a \times b \) 得到垂直于 \( a,b \) 所在平面的向量，用于计算法线、构建切线空间
- **投影**：向量 \( a \) 在单位向量 \( n \) 上的投影为 \( (a \cdot n) \cdot n \)

**第二层：光线求交——几何法 vs 代数法**

光线与球体求交有两种常用方法：

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 代数法（二次方程） | 联立光线参数方程和球面方程，解 \( at^2+bt+c=0 \) | 通用性强 | 数值不稳定（远距离时） |
| 几何法 | 利用勾股定理，先算球心到光线垂直距离 OH，再算半弦 PH | 数值更稳定 | 仅适用于球体 |

几何法核心推导：
1. `OC = C - S`：球心到射线起点的向量
2. `SH = dot(OC, D)`：OC 在射线方向上的投影
3. `OH² = |OC|² - SH²`：球心到射线的垂直距离（勾股定理）
4. 若 `OH² > r²` → 不相交
5. `PH = sqrt(r² - OH²)`：交点半弦长
6. 交点距离 `t = SH ± PH`，取正的最小值

**第三层：数值稳定性考量**

几何法避免了二次方程中 `b² - 4ac` 在远距离时的精度损失。当射线起点离球体很远时，`a ≈ 0`（方向向量单位化后），判别式可能出现灾难性抵消（catastrophic cancellation）。

### 关键公式

反射向量标准公式：
\[
R = I - 2(N \cdot I) \cdot N
\]

其中 \(I\) 是归一化入射方向（指向表面），\(N\) 是归一化法线。推导过程见附录。

## 三、动手实践（代码案例）

### 3.1 光线与球体求交——几何法

```glsl
/**
 * 射线与球体相交检测（几何法）
 * @param center 球心坐标（世界空间）
 * @param radius 球体半径
 * @param rayStart 射线起点
 * @param rayDir 射线方向（已归一化）
 * @return 交点到射线起点的距离，不相交返回-1.0
 *
 * 推导：
 * OC = C - S       球心到射线起点
 * SH = OC·D        球心在射线方向上的投影
 * OH = √(|OC|²-SH²) 球心到射线的垂直距离
 * PH = √(r²-OH²)   交点半弦长度
 */
float RayIntersectSphere(vec3 center, float radius, vec3 rayStart, vec3 rayDir)
{
    // 阶段1：基础几何关系
    vec3 OC = center - rayStart;
    float SH = dot(OC, rayDir);
    float OS_squared = dot(OC, OC);

    // 阶段2：垂直距离和相交判定
    float OH_squared = OS_squared - SH * SH;
    if (OH_squared > radius * radius) {
        return -1.0; // 不相交
    }

    // 阶段3：交点距离计算
    float PH = sqrt(radius * radius - OH_squared);
    float t1 = SH - PH;
    float t2 = SH + PH;

    // 阶段4：交点选择——选正方向最近交点
    float t = (t1 < 0.0) ? t2 : t1;
    if (t < 0.0) return -1.0;
    return t;
}
```

### 3.2 代数法（二次方程）对比

```glsl
// 标准二次方程解法（存在数值稳定性问题）
bool QuadraticIntersection(vec3 O, vec3 D, float r, out float t1, out float t2) {
    float a = dot(D, D);
    float b = 2.0 * dot(D, O);
    float c = dot(O, O) - r*r;

    float discriminant = b*b - 4.0*a*c;
    if(discriminant < 0.0) return false;

    t1 = (-b - sqrt(discriminant)) / (2.0*a);
    t2 = (-b + sqrt(discriminant)) / (2.0*a);
    return true;
}
```

### 3.3 反射向量——shader 直接使用

```glsl
// GLSL 内置函数
vec3 R = reflect(I, N); // I: 入射方向(指向表面), N: 法线

// 等价手动实现
vec3 R_manual = I - 2.0 * dot(N, I) * N;
```

## 四、进阶应用（≥500字）

### 与其他主题的关联

- **光线追踪**：光线-三角形求交（Möller–Trumbore 算法）是光线追踪的核心，Möller–Trumbore 算法基于重心坐标 + Cramer 法则，本质是求解线性方程组。光线-球体求交是其简化特例。
- **PBR**：BRDF 中的 Fresnel 项依赖反射/折射公式；GGX 法线分布函数的半程向量 \( H = \frac{L+V}{|L+V|} \) 依赖向量归一化。
- **阴影计算**：Shadow Ray 从着色点向光源发射，判断是否被遮挡，本质是光线-几何体求交。

### 工程中的真实用法

- **UE5 Lumen**：SDF（Signed Distance Field）光线步进（Ray Marching）利用距离场快速跳过空白区域，核心是迭代的球体追踪（Sphere Tracing）：`t += SDF(p + t*D)`，每次取 SDF 值作为步长保证不穿透。
- **Unity HDRP**：屏幕空间反射（SSR）使用 Hi-Z 光线步进，在深度金字塔上做层级求交，每步根据当前 mip 层的深度值决定步长。
- **碰撞检测**：GJK 算法（Gilbert–Johnson–Keerthi）用于凸体碰撞检测，核心依赖支撑函数和单纯形迭代，Minkowski 差概念。

### 常见优化策略

- **SIMD 批量求交**：4 条光线同时与同一三角形求交，利用 SSE/AVX 指令集并行计算
- **BVH 加速结构**：用 AABB（轴对齐包围盒）做粗检测，AABB 求交只需 3 次减法+比较（`t_min = max((min - O) / D, ...)`）
- **预计算**：球体半径平方 \(r^2\)、方向倒数 \(1/D\) 可预存避免重复计算
- **提前退出**：检测到 `OH² > r²` 立即返回，避免开方运算

## 五、源码解析和实践感悟（≥1000字）

### 关键实现路径

**几何法 vs 代数法的数值特性分析（补充）**

以射线起点距离球心 10000 单位，半径 1 单位为例：

**代数法**：`a = dot(D,D) = 1.0`，`b = 2*dot(D,O) ≈ 20000`，`c = |O|² - r² ≈ 100000000`。判别式 `b² - 4ac ≈ 400000000 - 400000000 ≈ 0`。在 float 精度下，`b²` 和 `4ac` 都是约 4e8 级别，相减后只剩几个 bit 有效精度，导致交点抖动甚至穿透。

**几何法**：先算 `OH² = |OC|² - SH²`。当射线几乎擦过球体时，`|OC|²` 和 `SH²` 非常接近，同样有抵消问题。但几何法可以通过选择参考点来缓解——将射线起点移到球心附近做计算，再回推距离。

```c++
// 改进版：先投影到球心附近再做几何法（补充）
float RayIntersectSphereStable(vec3 center, float radius, vec3 O, vec3 D) {
    // 先将射线起点沿方向平移到离球心最近的点
    vec3 OC = center - O;
    float t_proj = dot(OC, D);
    vec3 O_proj = O + t_proj * D;
    
    // 在新起点处做几何求交
    vec3 OC_new = center - O_proj;
    float OH2 = dot(OC_new, OC_new); // 此时 SH=0
    if (OH2 > radius * radius) return -1.0;
    
    float PH = sqrt(radius * radius - OH2);
    return t_proj - PH; // 回推距离
}
```

### 难点与易错点

**陷阱1：反射公式中 I 的方向**
反射公式 `R = I - 2(N·I)N` 中，**I 必须指向表面（从光线起点指向交点）**。如果传入的是光照方向 L（从表面指向光源），结果是错的。很多 shader 代码在这里混淆。

```glsl
// 正确：I 指向表面
vec3 I = normalize(hitPoint - rayOrigin);
vec3 R = reflect(I, N);

// 错误：L 指向光源
vec3 L = normalize(lightPos - hitPoint);
vec3 R_wrong = reflect(L, N); // 得到的是折射方向！
```

**陷阱2：光线方向非归一化**
几何法中 `SH = dot(OC, D)` 依赖于 D 是单位向量。如果 D 未归一化，SH 的几何意义丧失，`OH²` 计算错误，结果不可用。

**陷阱3：背面求交**
射线从球体内部出发时（`SH < 0` 且 `|OC| < r`），t1 为负、t2 为正，应取 t2。如果不处理，会报告不相交但实际射线在球内。

### 经验总结

1. **几何法优先**：对球体、胶囊体等简单几何体，几何法比代数法稳定，尤其在远距离场景（如太空渲染）
2. **避免在 shader 中做求交**：GPU 的 control flow divergence 使得分支求交开销大，尽量在 compute shader 中批量处理或使用 BVH 加速
3. **浮点精度意识**：`float` 只有约 7 位有效数字，大数相减是头号杀手。用 double 或重构公式
4. **反射公式的工程变体**：实际引擎中常用 `R = 2*(N·V)*N - V`（V 指向光源），这和标准公式等价但不容易搞混方向

## 六、面试准备

### 6.1 高频问法（≥8个）

**基础理解：**

Q1：点积和叉积在图形学中分别有什么应用？

A：点积用于计算投影长度（如 Lambert 漫反射 `N·L`）、判断方向一致性、计算向量夹角；叉积用于生成法线（三角形两边的叉积 → 面法线）、构建切线空间（N×T → B）、判断左右关系。

Q2：光线与球体求交的两种方法区别是什么？

A：代数法解二次方程 `at²+bt+c=0`，通用但数值不稳定；几何法用勾股定理算垂直距离再算半弦，仅适用于球体但更稳定。

Q3：为什么几何求交法比二次方程法更数值稳定？

A：二次方程中 `b²-4ac` 在远距离时出现大数相减抵消，float 精度下只剩几个 bit；几何法通过选取合适的参考点，将计算约束在局部坐标系中，避免了大量级相消。

**原理深入：**

Q4：MVP 矩阵变换中，为什么用 4×4 齐次坐标而不是 3×3？

A：3×3 只能表示线性变换（旋转、缩放），无法表示平移。齐次坐标将平移写入第 4 列，并用第 4 维 w 做透视除法，统一了所有仿射变换和透视投影。

Q5：如何判断一个点是否在三角形内？

A：三种方法：1) 重心坐标法——计算点在三角形内的重心坐标 \( (\alpha,\beta,\gamma) \)，若均在 [0,1] 范围内则在内部；2) 同侧法——用叉积判断点在每条边的同一侧；3) 面积法——点与三边组成的三个小三角形面积之和等于大三角形面积时在内部。

**实践应用：**

Q6：四元数相比欧拉角和旋转矩阵有什么优势？

A：四元数无万向节死锁（Gimbal Lock）；插值平滑（slerp）；存储紧凑（4 个 float vs 9 个）；组合旋转只需乘法。欧拉角直观但有死锁；矩阵占用空间大、插值困难。

Q7：在实际引擎中如何优化大量光线求交？

A：1) BVH/TLAS 空间加速结构做粗筛；2) 使用 compute shader 批量处理避免 divergence；3) AABB 包围盒先做快速剔除（只需 6 次比较）；4) 对静态场景预烘焙距离场（SDF）。

Q8：反射公式 `R = I - 2(N·I)N` 如何推导？

A：见附录原推导。核心思路：反射向量 R 和入射向量 I 关于法线 N 对称，I 在 N 上的投影为 `(N·I)N`，R 的末端到 I 的末端的向量是这个投影的两倍，方向相反，所以 `R = I - 2(N·I)N`。

### 6.3 一句话答案（≥5个）

- 图形学核心三个数学工具：向量运算（方向/投影）、矩阵变换（空间转换）、求交算法（光线-几何体）。
- 几何求交比代数求交更稳定的原因是：限制了数值运算的量级，避免大数相减。
- 反射公式的记忆口诀：入射向量减去两倍法线投影。
- 四元数优于欧拉角的根本原因：四元数是连续参数化旋转群 SO(3)，无奇点。
- GPU 上最省运算的剔除方式：AABB 求交——3 次按分量除法 + 3 次 min/max + 1 次比较。

**情景模拟：**

- 被问到"为什么用 MVP 矩阵"→ "Model 把物体从本地空间变换到世界空间，View 变换到相机空间，Projection 做透视投影到 NDC，三者合一可以用一个矩阵乘法完成。"
- 被问到"叉积的应用"→ "最常见的三个：求三角形法线、构建 TBN 切线空间、判断左右（如背面剔除中用叉积判断三角形法线朝向）。"

## 附录（模板外原内容收纳）

### 反射向量推导（两种方法）

> 以下为原笔记中反射向量的完整推导过程。

**方法一**

设入射光线向量 I 和反射平面法向量 N 之间的夹角为 θ。连接 I 的始端和 R 的末端，则有：

\( R = 2P - I \)（1）

设入射点 O 到 P 与 N 的交点的向量为 S，那么有：

\( P = I + S \)（2）

向量 S 即向量 -N 在向量 N 上的投影，根据投影公式有 \( S = \frac{(-N \cdot I)}{|N|^2} N \)，因为 N 是单位向量，简化得 \( S = -(N \cdot I) N \)。

将 S 代入（2），再将 P 代入（1）得：

\( R = I - 2(N \cdot I) N \)

**方法二（更直观）**

将 R 平移，与向量 N 的延长线相交。由于入射角等于反射角，且 I 和 R 长度相等，三角形 ION 是等腰三角形，故有 \( ON = 2S \)。

所以 \( R = I + 2S \)，而 S 是 -I 在 N 上的投影，即 \( S = -(-I \cdot N) N = (I \cdot N) N \)（方向与 N 相反），最终 \( R = I - 2(N \cdot I) N \)。

### 光线与球体求交——代数法推导

设球心 C、半径 r，射线 \( P(t) = S + tD \)，代入球面方程 \( |P - C|^2 = r^2 \)：

\( |S + tD - C|^2 = r^2 \)

令 \( O = S - C \)，展开得：

\( |O + tD|^2 = (O + tD)·(O + tD) = |D|^2 t^2 + 2(O·D)t + |O|^2 = r^2 \)

即标准二次方程：\( a t^2 + b t + c = 0 \)，其中 \( a = |D|^2 \), \( b = 2(O·D) \), \( c = |O|^2 - r^2 \)。

判别式 \( \Delta = b^2 - 4ac \)，若 \( \Delta < 0 \) 则不相交；否则 \( t = \frac{-b \pm \sqrt{\Delta}}{2a} \)。
