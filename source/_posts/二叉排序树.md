# 二叉排序树（BST）

二叉排序树（Binary Search Tree）：左子树所有节点 < 根 < 右子树所有节点，中序遍历得到有序序列。

## 完整实现代码

```c
#include<stdio.h>
#include<stdlib.h>
typedef struct SortTree {
	int data;//存放数据的数据域
	struct SortTree* left;//指针域 左指针
	struct SortTree* right;//指针域 右指针
}Node;
/*全局变量*/
Node* root;//根节点
 
void Init(int);//初始化操作
void insert(int);//插入操作
void show(Node*);
int delete_node(Node*, int);
Node* prev_node(Node*, Node*, int);
bool search(Node* root, int key);
int main()
{
	Init(8);
	insert(4);
	insert(2);
	insert(5);
	insert(10);
	insert(9);
	insert(13);
	show(root);
	delete_node(root, 8);
	delete_node(root, 13);
	printf("\n");
	show(root);
}
 
/*初始化根节点
int key : 根节点的值
*/
void Init(int key)
{
	root = (Node*)malloc(sizeof(Node));
	root->data = key;
	root->left = NULL;
	root->right = NULL;
}
 
void insert(int key)
{
	//定义一个临时指针 用于移动
	Node* temp = root;//方便移动 以及 跳出循环
	Node* prev = NULL;//定位到待插入位置的前一个结点
	while (temp != NULL)
	{
		prev = temp;
		if (key < temp->data)
		{
			temp = temp->left;
		}
		else if(key > temp->data)
		{
			temp = temp->right;
		}
		else
		{
			return;
		}
	}
 
	if (key < prev->data)
	{
		prev->left = (Node*)malloc(sizeof(Node));
		prev->left->data = key;
		prev->left->left = NULL;
		prev->left->right = NULL;
	}
	else
	{
		prev->right = (Node*)malloc(sizeof(Node));
		prev->right->data = key;
		prev->right->left = NULL;
		prev->right->right = NULL;
	}
}
 
void show(Node* root)
{
	if (root == NULL)
	{
		return;
	}
	show(root->left);
	printf("%d ", root->data);
	show(root->right);
}
/*查找元素key*/
bool search(Node* root, int key)
{
	while (root != NULL)
	{
		if (key == root->data)
			return true;
		else if (key < root->data)
			root = root->left;
		else
			root = root->right;
	}
	return false;
}
int delete_node(Node* node, int key)
{
	if (node == NULL)
	{
		return -1;
	}
	else
	{
		if (node->data == key)
		{
			//当我执行删除操作 需要先定位到前一个结点
			Node* tempNode = prev_node(root, node, key);
			Node* temp = NULL;
			/*
			如果右子树为空 只需要重新连接结点
			叶子的情况也包含进去了 直接删除
			*/
			if (node->right == NULL)
			{
				temp = node;
				node = node->left;
				/*为了判断 待删除结点是前一个结点的左边还是右边*/
				if (tempNode->left->data == temp->data)
				{
					Node* free_node = temp;//释放用的指针
					tempNode->left = node;
					free(free_node);
					free_node = NULL;
				}
				else
				{
					Node* free_node = temp;//释放用的指针
					tempNode->right = node;
					free(free_node);
					free_node = NULL;
				}
			}
			else if (node->left == NULL)
			{
				temp = node;
				node = node->right;
				if (tempNode->left->data == temp->data)
				{
					Node* free_node = temp;//释放用的指针
					tempNode->left = node;
					free(free_node);
					free_node = NULL;
				}
				else
				{
					Node* free_node = temp;//释放用的指针
					tempNode->right = node;
					free(free_node);
					free_node = NULL;
				}
			}
			else//左右子树都不为空
			{
				temp = node;
				/*往左子树 找最大值*/
				Node* left_max = node;//找最大值的临时指针
				left_max = left_max->left;//先到左孩子结点
				while (left_max->right != NULL) 
				{
					temp = left_max;
					left_max = left_max->right;
				}
				node->data = left_max->data;
				if (temp != node)
				{
					temp->right = left_max->left;
					free(left_max);
					left_max = NULL;
				}
				else
				{
					temp->left = left_max->left;
					free(left_max);
					left_max = NULL;
				}
			}
			
		}
		else if(key < node->data)
		{
			delete_node(node->left, key);
		}
		else if (key > node->data)
		{
			delete_node(node->right, key);
		}
	}
}
/*定位到待删除节点的前一个结点
Node* root 从根节点开始
Node* node 待删除的结点
int key 待删除数据
*/
Node* prev_node(Node* root, Node* node, int key)
{
	if (root == NULL || node == root)
	{
		return node;
	}
	else
	{
		if (root->left != NULL && root->left->data == key)
		{
			return root;
		}
		else if(root->right != NULL && root->right->data == key)
		{
			return root;
		}
		else if (key < root->data)
		{
			return prev_node(root->left, node, key);
		}
		else
		{
			return prev_node(root->right, node, key);
		}
	}
}
```

# 五、源码解析和实践感悟

## 1. BST 查找——O(h) 的二分思想

BST 查找本质上是二分查找的树形化：每次比较决定去左子树还是右子树，路径长度等于树高 h。平衡时 O(logN)，退化为链表时 O(N)。

```cpp
// C++ 模板版 BST 查找
template<typename K>
Node<K>* bst_search(Node<K>* root, const K& key) {
    while (root) {
        if (key == root->data)      return root;
        else if (key < root->data)   root = root->left;
        else                         root = root->right;
    }
    return nullptr;  // 未找到
}
// 递归版（简洁但可能栈溢出）
Node* bst_search_r(Node* root, int key) {
    if (!root || root->data == key) return root;
    return key < root->data ? bst_search_r(root->left, key)
                            : bst_search_r(root->right, key);
}
```

## 2. BST 删除——三种情况的统一处理

BST 删除是最复杂的操作，分三种情况：(1) 叶子节点直接删；(2) 单子节点用子节点替代；(3) 双子节点用前驱/后继替换。

```cpp
// C++ 版 BST 删除（递归，返回新子树根）
template<typename K>
Node<K>* bst_delete(Node<K>* root, const K& key) {
    if (!root) return nullptr;
    
    if (key < root->data) {
        root->left = bst_delete(root->left, key);
    } else if (key > root->data) {
        root->right = bst_delete(root->right, key);
    } else {  // 找到目标节点
        // 情况1&2：0或1个子节点
        if (!root->left) {
            auto tmp = root->right;
            delete root;
            return tmp;
        }
        if (!root->right) {
            auto tmp = root->left;
            delete root;
            return tmp;
        }
        // 情况3：两个子节点——找后继（右子树最小节点）
        auto successor = min_node(root->right);
        root->data = successor->data;               // 复制数据
        root->right = bst_delete(root->right, successor->data); // 删后继
    }
    return root;
}

Node* min_node(Node* node) {
    while (node && node->left) node = node->left;
    return node;
}
// 替换策略：前驱（左子树最大值）或后继（右子树最小值）都可以
// 选后继更常见（右子树一定存在）
```

## 3. BST 验证——递归检查上下界

判断一棵树是否是合法 BST，不能只检查左<根<右，必须维护上下界（所有左子树节点 < 根，所有右子树节点 > 根）。

```cpp
// 验证 BST：递归维护 (min, max) 区间
bool is_valid_bst(Node* root, long long min_val = LLONG_MIN, 
                               long long max_val = LLONG_MAX) {
    if (!root) return true;
    if (root->data <= min_val || root->data >= max_val)
        return false;
    return is_valid_bst(root->left,  min_val, root->data) &&
           is_valid_bst(root->right, root->data, max_val);
}
// 经典错误检查：只比较 root->left->data < root->data < root->right->data
//           5
//          / \
//         3   8
//        / \
//       2   6    ← 6 在 5 左子树中但 >5，非法 BST！
// 只比较父子节点无法发现 6 的错误
```

## 实践经验

1. **BST 性能完全取决于树的形状**：理想平衡下 O(logN) ≈ 20 次比较（100 万元素），退化链表下 O(N) = 100 万次。这就是为什么需要 AVL/红黑树保证平衡——生产环境不可接受随机退化。
2. **插入顺序决定退化风险**：升序插入 `[1,2,3,...,N]` 会产生完全右倾链表。随机插入期望树高 O(logN)，但理论最坏 O(N)。这也是 MySQL 用 B+ 树而非 BST 的原因之一——自增主键会直接导致 BST 退化。
3. **删除的双子节点替换有坑**：替换节点后必须递归删除原后继（而非简单置 NULL），因为后继可能有右子节点。许多教科书代码在此犯错。
4. **BST 的中序遍历 = 排序输出**：这个性质可以用来验证 BST 的合法性——中序遍历结果严格递增即可。时间 O(N)，空间 O(N)（存储遍历结果）或 O(h)（prev 指针原地比较）。
5. **递归删除的栈深度风险**：极端退化下递归深度 = N，可能栈溢出。迭代版删除需手动维护父节点指针，代码复杂度高 3 倍但安全。生产环境择机使用。
6. **BST 是理解更复杂树结构的基石**：AVL 树 = BST + 旋转平衡，红黑树 = BST + 颜色约束，B 树 = BST 的多叉扩展。掌握 BST 的插入查找删除是数据结构进阶的前提。

# 六、面试准备

## 面试问答

**Q1: BST 的定义和性质？**
A: 二叉排序树：对任意节点，左子树所有节点值 < 根节点值 < 右子树所有节点值。性质：(1) 中序遍历得到有序序列（升序）；(2) 查找/插入/删除复杂度 O(h)，h 为树高；(3) 没有重复值（一般规定）；(4) 最小值在最左节点，最大值在最右节点。

**Q2: BST 删除的三种情况？**
A: (1) **叶子节点**：直接删除，父节点对应指针置 NULL；(2) **单子节点**：用唯一子节点替换被删节点；(3) **双子节点**：找前驱（左子树最大值）或后继（右子树最小值），用其值覆盖被删节点，再递归删除前驱/后继节点。前驱/后继最多有一个子节点，转为情况 1 或 2。

**Q3: 如何判断一棵树是否是 BST？**
A: 不能只检查 `left < root < right`（会漏掉跨层违规）。正确做法：递归传递 (min, max) 区间的中序遍历检查是否严格递增。区间法 O(N) 时间 O(h) 空间。

**Q4: BST 为什么可能退化成链表？如何避免？**
A: 有序插入时每次新节点都在最右侧（最大值方向），形成右倾链表。避免方法：使用自平衡 BST（AVL 树：严格平衡，|左高-右高|≤1；红黑树：颜色约束保证黑高平衡）。标准库 `std::map` 就是红黑树实现。

**Q5: BST 的中序遍历复杂度？递归和迭代实现？**
A: O(N) 时间，O(h) 空间（递归栈）或 O(1) 空间（Morris 遍历）。递归遍历最常用，迭代版用栈模拟：一直向左并入栈到底，弹栈访问，转右子树重复。Morris 遍历利用空闲指针实现真 O(1) 空间但会临时修改树结构。

**Q6: BST 找第 K 小的元素？**
A: 中序遍历到第 K 个元素即可，O(K) 时间。优化：每个节点维护 `size`（子树节点数），则可在 O(logN) 内定位：`if (left_size >= K)` 去左子树；`else if (left_size + 1 == K)` 当前节点；`else` 去右子树找第 `K - left_size - 1` 小。

**Q7: 两个节点的最近公共祖先（LCA）怎么求？**
A: 利用 BST 有序性：从根向下，若 `p,q < root` 去左子树，若 `p,q > root` 去右子树，否则当前 root 就是 LCA（p 和 q 分居两侧或其中一个是 root）。O(h) 时间 O(1) 空间，比普通二叉树的 O(N) 解法快得多。

**Q8: BST 和堆的区别？各自用途？**
A: BST 有序（中序遍历有序序列），支持高效范围查询；堆只保证堆顶是最大/最小值，内部无序。BST 用于需要排序的查找（`std::map`），堆用于优先队列（`std::priority_queue`）。构建堆 O(N)，构建 BST O(N logN)。

## 陷阱与反问

| 陷阱 | 错误认知 | 正确理解 |
|------|---------|---------|
| `root->left->data < root->data < root->right->data` 就是 BST | 只检查父子节点，跨层可能违规 | 必须维护上下界或中序遍历检查严格递增 |
| BST 查找永远是 O(logN) | 仅当树平衡时如此 | 退化链表时 O(N)，最坏情况与数组顺序查找相同 |
| 删除只需处理被删节点 | 双子节点情况需要找前驱/后继并递归删除 | 替换后原前驱/后继位置需要重新连接 |
| BST 不能有重复值 | 可以约定等值放左子树或右子树 | 但标准定义一般不允许重复，实际实现可扩展 |
| 递归 BST 操作没问题 | 极端退化时递归深度 = N | 考虑用迭代版或在平衡树结构上操作 |
