# 位运算

3次重复出现的数字清零

```
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ones = 0; // 记录出现1次的位
        int twos = 0; // 记录出现2次的位
        
        for (int num : nums) {
            // 更新ones：当twos对应位为0时，ones与num异或
            ones = (ones ^ num) & ~twos;
            
            // 更新twos：当ones对应位为0时，twos与num异或
            twos = (twos ^ num) & ~ones;
        }
        
        return ones;
    }
};
```

|  |  |  |  |
| --- | --- | --- | --- |
| 出现次数 | `ones`  变化 | `twos`  变化 | 表达式 |
| 初始状态 | 0 | 0 | - |
| 第一次出现 | `(0^1)&~0=1` | `(0^1)&~1=0` | 位在 `ones` |
| 第二次出现 | `(1^1)&~0=0` | `(0^1)&~0=1` | 位在 `twos` |
| 第三次出现 | `(0^1)&~1=0` | `(1^1)&~0=0` | 位被清除 |
| 第四次出现 | `(0^1)&~0=1` | `(0^1)&~1=0` | 重新开始 |

### 位运算统计（通用）

```
int findUnique(vector<int>& nums) {
    int result = 0;
    // 遍历32位
    for (int i = 0; i < 32; i++) {
        int count = 0;
        int mask = 1 << i;
        for (int num : nums) {
            if (num & mask) {
                count++;
            }
        }
        // 如果该位出现次数不是x的倍数   出现几次就是几
        if (count % 4 != 0) {
            result |= mask;
        }
    }
    return result;
}
```

## 一、核心概念

- **定义**：位运算是直接对整数的二进制位进行操作的运算，包括按位与（&）、或（|）、异或（^）、取反（~）、左移（<<）、右移（>>）
- **关键词**：按位操作、布尔代数、mask（掩码）、popcount、`n & (n-1)`、`n & -n`（lowbit）、三进制状态机
- **适用场景/边界**：高性能场景（O(1) 位操作替代循环）、状态压缩（位掩码存多状态）、算法题（找唯一数、2的幂判断）；边界：仅适用于整数类型，对有符号数右移行为依赖实现

## 二、详细解析（≥200字）

- **原理拆解（三层递进）**：
  - **第一层——六大基本运算**：`&` 任意位清零（掩码保留）、`|` 任意位置 1、`^` 翻转指定位且满足 a^a=0、`~` 全局按位取反、`<<` 左移等价乘 2^n、`>>` 右移等价除 2^n
  - **第二层——三大经典公式**：`n & (n-1)` 清零最低位 1（可判 2 的幂、统计 1 个数）；`n & -n` 提取最低位 1（树状数组核心）；`a ^= b; b ^= a; a ^= b` 无临时变量交换
  - **第三层——三进制状态机**：用 `ones` 和 `twos` 两个变量模拟每位 2-bit 计数器（00→01→10→00），实现"出现 3 次清零"。真值表：`ones = (ones ^ num) & ~twos` 仅在 twos=0 位更新；`twos = (twos ^ num) & ~ones` 仅在 ones=0 位更新
- **关键数据结构/接口**：`__builtin_popcount/clz/ctz`（GCC/Clang 内建，映射 CPU 指令 POPCNT/LZCNT/TZCNT）
- **关键公式/复杂度**：`n & (n-1) == 0` 判 2 的幂 O(1)；popcount 循环 `while(n) { n &= n-1; count++; }` 只迭代 1 的位数次

## 三、动手实践（代码案例）

```c++
#include <iostream>
#include <bitset>

int main() {
    unsigned n = 0b101100;  // 十进制 44

    // 1. 基础位运算
    std::cout << std::bitset<8>(n) << std::endl;           // 00101100
    std::cout << std::bitset<8>(n & (n-1)) << std::endl;   // 00101000  清零最低位1
    std::cout << std::bitset<8>(n & -n) << std::endl;      // 00000100  取最低位1
    
    // 2. 判断2的幂
    auto isPow2 = [](unsigned x) { return x && !(x & (x-1)); };
    std::cout << isPow2(64) << " " << isPow2(100) << std::endl;  // 1 0
    
    // 3. 统计1的个数（popcount）
    auto popcount = [](unsigned x) {
        int cnt = 0;
        while (x) { x &= x-1; ++cnt; }
        return cnt;
    };
    std::cout << popcount(n) << std::endl;  // 3
    
    // 4. 找到数组中唯一出现一次的数（其他出现两次）
    int arr[] = {4, 1, 2, 1, 2};
    int single = 0;
    for (int x : arr) single ^= x;
    std::cout << single << std::endl;  // 4

    // 5. 位掩码状态压缩
    enum Perm { READ = 1<<0, WRITE = 1<<1, EXEC = 1<<2 };
    unsigned perm = READ | WRITE;           // 011
    std::cout << (perm & READ) << std::endl;  // 1 (有读权限)
    
    return 0;
}
```

- **预期**：掌握 `n&(n-1)`、`n&-n`、异或消去、位掩码四大模式
- **补充**：`__builtin_popcount(n)` 比手写循环快 50-100 倍（映射 POPCNT 指令）

## 四、进阶应用（≥500字）

- **与其他主题的关联**：与数据结构（树状数组的 lowbit 操作）、算法优化（动态规划状态压缩）、底层编程（寄存器和标志位操作）、加密哈希（位扩散和混淆）强相关
- **工程中的真实用法**：
  - **树状数组（Fenwick Tree）**：`lowbit(i) = i & -i` 是核心操作，实现前缀和 O(log n) 更新和查询
  - **状态压缩 DP**：用 `int` 的 32 位存储 32 个布尔状态，`dp[mask]` 中 `mask` 的置位位表示已选择/已访问的元素，时间复杂度从 O(n!) 降到 O(2^n·n)
  - **权限系统**：`READ=0b001, WRITE=0b010, EXEC=0b100`，`user_perm = READ | WRITE`，`if (user_perm & WRITE)` 一次 AND 判权
  - **布隆过滤器**：用多个哈希函数置位位图，`bitmap[index] & (1 << offset)` 判断可能存在，误判率可控
- **常见优化策略**：
  - **算法层面**：`n & (n-1)` 可用于 Brian Kernighan 算法（汉明距离计算）；`n | (n+1)` 设置最低位 0 为 1；`n & (n+1)` 清除尾随的 1
  - **数据结构**：用 `uint64_t` 存 64 个布尔状态替代 `bool[64]`，内存减 64 倍、一次比较完成多条件检测
  - **内存访问**：位图索引（Bitmap Index）在数据库查询中加速 AND/OR/NOT 操作——CPU 可按 word 并行处理 64 位
  - **硬件加速**：POPCNT 指令（`__builtin_popcount`）常用于机器学习特征哈希、集合相似度计算；BMI 位操作指令集（`_blsr_u64`、`_blsi_u64`）加速 `n&(n-1)` 和 `n&-n`
  - **具体技巧**：对有符号数用 `>>` 可能算术移位（补符号位），用 `unsigned` 保逻辑移位；用 `1u << 31` 避免 `1 << 31` 的 UB（int 溢出）

## 五、源码解析和实践感悟

### 1. 位运算的核心技巧

```c++
// 常用位运算模板
inline bool is_power_of_two(unsigned n) { return n && !(n & (n - 1)); }
inline int lowbit(int n)              { return n & -n; }         // 最低位的1
inline int clear_lowbit(int n)        { return n & (n - 1); }    // 清除最低位1
inline int count_ones(unsigned n)     { return __builtin_popcount(n); }

// 异或性质：a ^ a = 0, a ^ 0 = a, a ^ b ^ a = b
// 数组中找唯一出现一次的数（其他都出现两次）：全异或即可
int single = 0;
for (int x : nums) single ^= x;  // 成对的消掉，剩唯一的
```

### 2. 三进制状态机（出现三次清零）

```c++
// 每一位独立维护 2-bit 计数器：00 → 01 → 10 → 00
int ones = 0, twos = 0;
for (int num : nums) {
    ones = (ones ^ num) & ~twos;  // 仅在 twos=0 的位上异或
    twos = (twos ^ num) & ~ones;  // 仅在 ones=0 的位上异或
}
return ones;  // 只出现一次的数

// 真值表验证：
// 当前(ones,twos) + num 位1 → 新(ones,twos)
// (0,0) + 1 → (1,0)  第一次出现
// (1,0) + 1 → (0,1)  第二次出现
// (0,1) + 1 → (0,0)  第三次出现 → 清零
```

### 3. 编译期位运算

```c++
// constexpr 位运算在编译期完成
constexpr int flags = (1 << 0) | (1 << 2) | (1 << 5);  // 编译期计算 = 37

// 位域打包（不依赖编译器布局）
constexpr uint32_t pack(uint8_t r, uint8_t g, uint8_t b, uint8_t a) {
    return (r << 24) | (g << 16) | (b << 8) | a;  // RGBA 编译期打包
}
```

### 实践经验

1. **异或找唯一**：所有出现偶数次的数异或归零，唯一奇数次的留下。LeetCode 136 经典
2. **`n & (n-1)` 清零最低位1**：可用于判断 2 的幂、统计二进制位中 1 的个数
3. **`n & -n` 取最低位1**：树状数组（Fenwick Tree）的核心操作
4. **`__builtin_popcount/clz/ctz`**：gcc/clang 内建函数，一条 CPU 指令完成，比手写循环快百倍
5. **位掩码优于 bool 数组**：用 `uint32_t flags` 存 32 个布尔状态，O(1) 位测试/置位
6. **SIMD 位运算**：`_mm_and_si128` 等指令一次处理 128/256 bit，批量位图操作性能极致

## 六、面试准备

### Q&A（8题）

**Q1: 异或运算的核心性质？**
A: a^a=0, a^0=a, 满足交换律和结合律。可用于找出现奇数次的数

**Q2: 如何判断一个数是2的幂？**
A: `n > 0 && (n & (n-1)) == 0`。2的幂的二进制只有一个1，n-1 使低位置1，AND 为零

**Q3: 怎么找出最低位的1？**
A: `n & -n`。补码中 -n = ~n+1，取反后最低位1保留，其余取反

**Q4: 统计二进制中1的个数最快方法？**
A: `__builtin_popcount(n)` 一条 CPU 指令（POPCNT）。或 `n &= n-1` 循环计数

**Q5: 不用临时变量交换两个数？**
A: `a ^= b; b ^= a; a ^= b;` 三次异或完成交换。实际比临时变量慢，仅面试展示

**Q6: 位运算实现加法？**
A: `while(b) { carry = a&b; a = a^b; b = carry<<1; }`，异或为无进位加，与为进位

**Q7: 为什么 `n & -n` 得到最低位1？**
A: 补码表示 `-n = ~n+1`，~n 翻转所有位，+1 将最低位1及之后进位复原

**Q8: 位掩码相比 bool 数组的优势？**
A: 一个 int 存 32 状态，内存减少 32 倍，一次位运算操作多状态，cache 友好

### 陷阱与反问（5个）

1. **陷阱**：`1 << 31` 对 32 位 int 是 UB（符号位溢出）— 用 `1u << 31`
2. **反问**：位运算比普通运算快吗？→ 不一定。现代编译器已能自动优化 `n/2` 为 `n>>1`，手写位运算可能反而不佳
3. **陷阱**：`~0` 对 signed int 结果是 -1 而非全 1 — 用 `~0u`
4. **反问**：`n & (n-1)` 还能干什么？→ 汉明距离（统计异或结果中 1 的个数）
5. **陷阱**：位运算优先级低于 `==` — `a & b == 0` 等价 `a & (b==0)`，必须加括号 `(a & b) == 0`

### 一句话答案（5个）

1. **`a^a=0`**：成对消去，找唯一出现奇数次的数
2. **`n&(n-1)`**：清零最低位1，判断2的幂
3. **`n&-n`**：取最低位1，树状数组核心
4. **`popcount`**：CPU 硬件指令，比手写快百倍
5. **位运算优先级**：低于比较符，必须加括号
