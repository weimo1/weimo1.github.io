# 体积云渲染（云海/云层）

> 适用范围：Ray Marching 体积云、噪声密度建模、Beer 定律光照、蓝噪声抖动

## 一、一句话结论

体积云 = **包围盒 Ray Marching + 多层噪声密度（Shape/Detail/Weather） + Beer 吸收 + Henyey-Greenstein 内散射 + 蓝噪声抖动消除分层**。64 步即可获得不错效果，结合大气散射透射率 LUT 实现天空融合。

---

## 二、核心概念解析（≥200字）

### 2.1 三个核心要素

每个像素点沿视线 Ray Marching 时需要计算：

| 要素 | 含义 | 算法 |
|------|------|------|
| **密度** | 当前位置有云的概率/浓度 | Shape Noise FBM + Detail Worley + Height Gradient |
| **光能** | 太阳光照到当前位置还剩多少 | Beer 定律：T = exp(-∫σ ds) |
| **反射比** | 多少光能反射到眼睛 | Henyey-Greenstein 相位函数 |

### 2.2 噪声层级

```
Weather Map（全局） → 云覆盖度、降雨、云类型
    ↓
Shape Noise（大尺度） → 云团形状和分布（FBM）
    ↓
Detail Noise（小尺度） → 边缘侵蚀（Worley/FBM）
    ↓
Height Gradient → 云底圆化、云顶消隐
```

## 三、源码解析与实践感悟（≥1000字）

### 3.1 密度采样（核心）

```glsl
float SampleShapedensity(vec3 worldPos) {
    vec3 localPos = (worldPos - kCloudBoxMin) / kCloudBoxSize;
    if (any(lessThan(localPos, vec3(0.0))) || any(greaterThan(localPos, vec3(1.0))))
        return 0.0;

    // 1. Shape Noise（FBM 叠加）
    vec4 lowshape = texture(_ShapeNoiceTex, localPos * 0.8);
    float shapeFBM = lowshape.g * 0.525 + lowshape.b * 0.25 + lowshape.a * 0.125;
    float density = remap(lowshape.r, saturate(1.0 - shapeFBM), 1.0, 0.0, 1.0);

    // 2. 高度梯度（圆化云底、云顶消隐）
    float heightGradient = GetDensityHeightGradient(worldPos, kCloudBoxMin.y, kCloudBoxMax.y);
    float roundButton = saturate(remap(heightGradient, 0, 0.07, 0, 1));
    float roundTop = saturate(remap(heightGradient, 0.2, 1, 1, 0));
    density *= roundButton * roundTop * densityButton * densityTop * 2;

    // 3. Weather Map
    vec2 weatherUV = worldPos.xz * 0.0038;
    vec4 weather = texture(_WeatherNoiceTex, weatherUV);
    float cloudCoverage = mix(0, 1, _CloudCoverage);  // 控制覆盖度

    // 4. Detail Noise（Worley FBM 侵蚀）
    vec3 detailNoise = texture(_DetailNoiceTex, worldPos * 0.014).rgb;
    float detailFBM = detailNoise.r * 0.5 + detailNoise.g * 0.25 + detailNoise.b * 0.125;
    density -= (1 - detailFBM) * densityScale * 0.1;

    // 5. 阈值过滤 + 缩放
    if (density < 0.004) density = 0.0;
    density = max(0, density - 0.004) * 1.3 * 0.15;
    return density * 0.8;
}
```

**FBM 系数 (0.5, 0.25, 0.125)**：经典的 octave 衰减，低频权重最高。

### 3.2 包围盒求交（Slab 方法）

```glsl
bool RayIntersectCloudBox(vec3 ray_origin, vec3 ray_dir, out float t_min, out float t_max) {
    vec3 inv_dir = 1.0 / ray_dir;
    vec3 t0 = (box_min - ray_origin) * inv_dir;
    vec3 t1 = (box_max - ray_origin) * inv_dir;
    vec3 t_near = min(t0, t1);
    vec3 t_far = max(t0, t1);
    t_min = max(max(t_near.x, t_near.y), t_near.z);
    t_max = min(min(t_far.x, t_far.y), t_far.z);
    t_min = max(t_min, 0.0);
    return t_max > t_min && t_max > 0.0;
}
```

### 3.3 蓝噪声抖动消除分层

```glsl
vec2 blueNoiseUV = gl_FragCoord.xy / iResolution.xy * 8.0;
float blueNoise = texture(blueNoiseTexture, blueNoiseUV).r;
float initial_jitter = blueNoise * step_size;
float t = t_min + (initial_jitter + float(i)) * step_size;
```

**效果对比**：
- **无抖动**：明显分层条纹
- **种子函数**（`fract(sin(...))`）：分层几乎消失，但边缘不饱满
- **hash12**：分层消失、饱满，开销更大
- **蓝噪声**：一次纹理采样，分层减弱但不如 hash 彻底

### 3.4 光照计算

```glsl
// Beer 定律：透射率
float absorption = density * step_size;
float steptransmittance = exp(-absorption);

// HG 相位函数（双瓣）
float sunPhase = DualLobPhase(0.8, -0.3, 0.3, cosTheta);

// 结合大气散射
vec3 sunAtmosphereTransmittance = TransmittanceToAtmosphere(params, currPos, -sunDir, transmittanceLUT);

// 散射贡献
vec3 stepScattering = sunColor * sunAtmosphereTransmittance * sunPhase;
vec3 sigmaS = vec3(density);
vec3 sactterLitStep = transmittance * (sigmaS * stepScattering * step_size);
scattering += sactterLitStep;
transmittance *= steptransmittance;
if (transmittance < 0.01) break;  // 早停
```

**最终混合**：`radiance = radiance * transmittance + scattering`（云后的大气被云遮挡 + 云自身散射）。

### 3.5 踩坑记录

- **密度一大就全白炸亮**，薄处灰不透，厚处像发光体 → 需要仔细调 `sigmaS/sigmaE` 平衡
- **性能**：64 步 + 多层噪声采样 + 大气透射率查询 = 昂贵
- **噪点**：需要 TAA 或双边滤波后处理
- **与天空融合**：需要使用相同的透射率 LUT 保证一致性

## 四、面试准备

### 高频问法（≥8个）

1. **体积云渲染的基本流程？** → 包围盒 Ray Marching → 每一步采样密度（多层噪声）→ 计算 Beer 吸收 + HG 内散射 → 累加
2. **噪声层级如何分工？** → Weather Map（覆盖度/类型）→ Shape Noise FBM（云团形状）→ Detail Worley（边缘侵蚀）→ Height Gradient（云底圆化/云顶消隐）
3. **如何消除 Ray Marching 的分层现象？** → 蓝噪声抖动初始步进偏移 + hash12 每步独立随机偏移
4. **Beer 定律在体积云中如何应用？** → 透射率 = exp(-∫σ·density·ds)，每步累乘衰减
5. **Henyey-Greenstein 相位函数的参数 g 含义？** → g∈(-1,1)，负=后向散射，0=各向同性，正=前向散射；云通常用正值（0.3-0.8）
6. **如何与大气散射结合？** → 云中每个采样点用 TransmittanceLUT 查询太阳光到达该点的大气衰减
7. **早停（early termination）条件？** → transmittance < 阈值（如 0.01），再往后的贡献可忽略
8. **为什么云的颜色不是纯白？** → 大气散射染上蓝色调 + 太阳光在云中多次散射产生灰度
9. **性能优化手段有哪些？** → 低分辨率渲染 + TAA 重建、自适应步长、减少噪声 octave、降低 Detail Noise 采样频率

### 反问点（≥5个）
- 双瓣 HG 相位函数（两个 g）的物理意义？
- Weather Map 为什么只采样 xz 平面？
- 为什么 localPos * 0.8 而不是 * 1.0？
- 云的包围盒如何确定大小和位置？
- 高度雾和体积云能否共用密度场？

### 一句话答案（≥5个）
- 体积云 = Ray Marching + 噪声密度 + Beer 消光
- FBM = 多层 octave 叠加噪声
- 蓝噪声抖动 = 低成本消除分层
- HG 相位 = 光在云中偏向哪个方向散射
- 早停 = 透射率太低后面不用算了

### 原：光照要点
- 吸收（absorption）：光被水/颗粒吸收减弱
- 内散射（in-scattering）：其它方向散射到视线
- 外散射（out-scattering）：散射到其它方向
- Beer 定律：基于光学厚度计算透射率
- 糖堆效应：光的内散射累积
